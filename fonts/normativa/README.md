# Normativa i portals oficials

Aquest índex separa les normes de les pàgines de consulta. Una norma pot haver sigut modificada o afectada per resolucions judicials; per això cal obrir sempre la font oficial i comprovar l’estat abans d’usar-la.

## Organització

- `estatal/`: legislació estatal.
- `gva/eso/`: normativa valenciana d’Educació Secundària Obligatòria.
- `gva/batxillerat/`: fonts valencianes verificades de Batxillerat.
- `gva/fp/`: fonts valencianes verificades de Formació Professional.
- `gva/inclusio/`: fonts valencianes d’inclusió educativa.
- `gva/inici-curs/2026-2027/`: instruccions verificades del curs 2026-2027.

Les carpetes reservades no impliquen que ja hi haja una norma aplicable registrada.
