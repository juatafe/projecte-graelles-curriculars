# Fonts del projecte

Aquest directori conserva les fonts que poden justificar afirmacions curriculars
o normatives. El fitxer principal és [`registre-fonts.md`](registre-fonts.md).

## Procediment

1. `gestor-fonts` localitza el document en un portal oficial.
2. Registra organisme, títol, URL, apartat o article, etapa, data de consulta i estat.
3. `extractor-normativa` només extreu dades de fonts registrades.
4. El verificador comprova que cada afirmació conserva la seua font i ubicació.

Una pàgina inicial d’un portal no substituïx el document normatiu concret. Una
font `PENDENT` no pot justificar una afirmació definitiva.

Estats permesos: `VERIFICADA`, `PENDENT`, `NO APLICABLE`.

Portals oficials de partida:

- [BOE](https://www.boe.es/): normativa estatal.
- [DOGV](https://dogv.gva.es/): normativa de la Generalitat Valenciana.
- [Conselleria d’Educació](https://ceice.gva.es/va/web/educacion): informació educativa.
- [Formació Professional](https://ceice.gva.es/va/web/formacion-profesional): informació de FP.
- [Ordenació acadèmica](https://ceice.gva.es/va/web/ordenacion-academica): informació d’ordenació acadèmica.
