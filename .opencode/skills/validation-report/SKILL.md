# Informe de validació

Retorna cada criteri amb `PASS`, `FAIL` o `NOT TESTED`, l’evidència, les
limitacions i els canvis fora d’abast. Acaba amb `READY FOR HUMAN REVIEW` o
`NOT READY`. No edites la graella.
